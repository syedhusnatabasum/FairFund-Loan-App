# FairFund – Interest-Free Loan Application

## About the Project
FairFund is a Flask-based web application designed to provide an interest-free loan management system. It helps users apply for loans and track their repayment status.

## Features
- User Registration and Login
- User Verification
- Interest-Free Loan Applications
- Admin Loan Approval and Rejection
- Loan Repayment Tracking
- User Dashboard
- Admin Dashboard

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Installation

1. Clone the repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
